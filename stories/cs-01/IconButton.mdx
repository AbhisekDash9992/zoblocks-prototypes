## Properties, Variants and States

**Type** describes the visual family. **State** describes interaction. Committed criteria determine the contextual **Type**; opening an editor or hovering a button does not mean applied.

### Practical guidance

- Use a recognizable icon for a compact action, with a specific accessible name such as “Filter” or “Remove Sort.”
- Use Ghost-primary when matching criteria are committed. Provide contextual text or a summary so applied status is understandable beyond color.
- Prefer a text button when the action is unfamiliar or needs explanation. A tooltip does not replace a visible label in those situations.
- Do not use this pilot to infer unsupported Sizes, Shapes, Types, production semantics or clinical behavior.

## Accessibility

**Limitations:** the 24px control needs touch-target review; tooltips are pointer-inert, and hover-only Escape requires trigger focus. Human assistive-technology review remains open.

- **Semantics:** native button; the accessible label remains when tooltips are disabled. SVG and slot are decorative.
- **Keyboard:** Tab / Shift+Tab moves focus; Enter / Space activates. Native disabled buttons cannot activate and are skipped by sequential navigation.
- **Tooltip:** opens on hover/focus; pointer leave, blur, click, activation keys and scroll dismiss it. Escape dismisses while the trigger is focused. Its open-time `role="tooltip"` description is supplemental; essential instructions must remain visible.
- **Review:** description preservation, assistive technology and hoverable-content behavior remain unresolved.

See CS-02 for the label-only Tooltip reference. Existing Data Grid consumers, including Remove Sort, retain their current appearance and behavior.

Forced-colors uses a solid system Highlight outline; disabled buttons have no hover/focus background or ring.

The anatomy shows the neutral ring. Leaders end on the stated features; dashed/dotted slot and glyph-box guides are construction only. Keyboard checks remain separate from human accessibility review.
