# Button

CS-04 · Oxygen Light reference · Designer review, non-production

## Overview

A Button performs the action named by its visible label. One reusable renderer covers **120 visual variants**: 2 Shapes × 5 Types × 3 Sizes × 4 States, with independently optional leading and trailing decorative icons.

<details>
<summary>Source evidence and boundaries</summary>

Designer-supplied component inspection, 22 October 2026: 120 variants, complete extraction, no inspection errors. Geometry, text size/line height, root colors, edge colors and focus effects are recorded for every variant. Only derived measurements and synthetic examples appear here.

Component variable alias IDs remain unresolved. The tables distinguish verified values from local semantic mappings and uninspected properties. All specimens explicitly opt into **Light** through `data-oxygen-mode="light"`. Dark component parity is unverified. No prototype consumer is migrated and no shared TF-01 definition changes.

## Accessibility

- Use a specific, visible action label. It supplies the accessible name; preserve it when adding ARIA props. Icon-only actions belong to CS-01.
- Keep native button keyboard, pointer, form and disabled semantics. Do not replace disabled with styling or aria-disabled alone.
- Tab gives a visible two-layer focus ring. Disabled has no activation or tab stop. Forced-colors mode uses a system-color outline.
- Decorative SVGs are hidden from assistive technology and are non-focusable; they inherit the separate icon role. No essential meaning relies only on color or artwork.
- Heights are 24–40px. Compact controls and reduced-contrast disabled appearances retain the source geometry and need contextual accessibility review; full touch-target compliance is not claimed.
- Browser checks cover activation, focus and native semantics, not screen-reader certification. Review zoom, contrast, forced colors and touch use in the intended context.
