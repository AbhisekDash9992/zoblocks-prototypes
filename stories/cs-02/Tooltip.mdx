No shortcut slot or shortcut variant was verified in Figma. A shortcut hint is an optional proposed enhancement, never a requirement for all Tooltips. Show one only when the shortcut is implemented, active and useful in its context. Keep the label meaningful without it.

## Behavior

The shared Data Grid Tooltip opens on hover or focus. Pointer leave, blur, pointer down, click, Enter, Space and captured scroll dismiss it. Escape dismisses while its trigger has focus. Popup-open suppression persists through programmatic focus restoration; a new hover or blur/focus interaction re-arms it. ## Usage

Use a brief, specific label for a familiar action. Keep essential instructions and clinical meaning visible in the surrounding interface. Tooltips contain no interactive controls. Avoid long explanations; the limited longer-label example checks wrapping without proposing a rich-content variant.

## Accessibility

The trigger is a native button with an independent accessible name. The open portal has `role="tooltip"`; the shared implementation adds `aria-describedby` while visible and removes it on dismissal. Use keyboard focus as well as hover to inspect the example. A shortcut is supplemental, and the proposed action remains available by button.

Existing limitations remain: hover-only Escape is not handled when focus is elsewhere, the tooltip is pointer-inert and cannot be hovered, and existing description attributes are not preserved by the shared implementation. These checks do not establish full accessibility conformance. Screen-reader announcement, touch suitability and hoverable-content expectations need human review.

## Open issues

Tooltip placement uses its rendered dimensions. It normally appears below the trigger with a 6px gap, adjusts horizontal alignment near viewport edges while preserving visual association with the trigger, and flips above when there is insufficient space below. When neither side fully fits, a viewport-constrained fallback is used where feasible. Exceptionally large tooltips may still overlap the trigger or exceed the available viewport.

Shortcut visuals and semantics remain a proposal. Long-text limits, touch interaction and assistive-technology behavior remain unresolved. CS-01 and the separate Data Grid route retain their accepted appearance and behavior.
